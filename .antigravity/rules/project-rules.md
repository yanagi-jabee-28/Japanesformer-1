# Japanesformer プロジェクト開発ルール

このプロジェクトの開発においては、以下のルールを厳守してください。

## 1. 言語およびコメント規約
- **コード内のコメントはすべて日本語で記述すること**。
- 関数やクラスのドキュメンテーション文字列（docstring）も日本語で詳細に記述する。
- 変数名、関数名、クラス名などの識別子はすべて**英語**を使用し、**ローマ字命名は禁止**とする（例: `henkan` はNG、`transform` はOK）。

## 2. 実装およびアルゴリズム規約
- **全単射（可逆性）の保証**: `transform` 関数および関連する復号処理は、如何なるひらがな・カタカナ・特殊文字・英数字の組み合わせに対しても完全に元に戻る（全単射）ように実装し、テストでこれを厳密に証明すること。
- **波状変換の整合性**: 位置依存シフトにおける `position_counter` は、日本語の母音グループに属する文字、および暗号化対象となる英数字（A-Z, a-z, 0-9）が処理された場合のみインクリメントし、それ以外の透過記号や空白文字ではインクリメントしない。これにより、暗号化と復号化でカウンターの同期が崩れることを防ぐ。

## 3. テスト規約
- テストは標準の `unittest` を使用し、`python -m unittest discover` で実行可能な構成にすること。
- 全単射性をテストするために、ランダムな文字生成（日本語・英数字混合）によるラウンドトリップテストを最低1000回以上実行するテストケースを含めること。

## 4. フロントエンド・アーキテクチャ規約（責務分離の原則：SoC）
WebUIのメンテナンス性を最大化し、デザインやロジック of UI の調整を独立して安全に行えるよう、以下の3層構造（分離原則）を厳格に維持すること。
- **【構造層】`index.html`**: UI要素の骨格（DOM）定義のみに専念する。インラインスタイル（`style="..."`）やインラインスクリプト（`onclick="..."`）の記述は一切禁止とする。
- **【表現層】`assets/css/style.css`**: すべての視覚表現・スタイルを統括する。カラー、ぼかし強度、アニメーション周期などの「後から微調整が予想される定数」は、すべて冒頭の `:root`（CSS変数）に定義し、一撃で一括管理できる体制を維持する。
- **【論理層】`assets/js/`**:
  - `pyodide-core.js`: WebAssemblyランタイム（Pyodide）およびPythonコアロジックとのブリッジに専念し、DOMの存在を知ってはならない。
  - `app.js`: 構造層（DOMイベント）と論理層（Pyodide）の仲介（コントローラー）に専念し、スタイルの直接変更や暗号化アルゴリズムの直接実装を行ってはならない。

## 5. 暗号化拡張規約（英数字のシーザー暗号対応）
- 日本語のリズム維持というコア特性を損なわない範囲において、文字列内に含まれる「数字（0-9）」および「アルファベット（A-Z, a-z）」は、独立したシーザー暗号（文字種の枠内での循環シフト）を適用する。
- 大文字は「A-Z」、小文字は「a-z」、数字は「0-9」の各文字空間の内部だけで循環させ、大文字が小文字や数字に化けるような境界の逸脱を起こしてはならない（文字種属性の完全維持）。
