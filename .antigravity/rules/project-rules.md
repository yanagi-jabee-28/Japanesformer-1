# Japanesformer プロジェクト開発ルール

このプロジェクトの開発においては、以下のルールを厳守してください。

## 1. 言語およびコメント規約
- **コード内のコメントはすべて日本語で記述すること**。
- 関数やクラスのドキュメンテーション文字列（docstring）も日本語で詳細に記述する。
- 変数名、関数名、クラス名などの識別子はすべて**英語**を使用し、**ローマ字命名は禁止**とする（例: `henkan` はNG、`transform` はOK）。

## 2. 実装およびアルゴリズム規約
- **全単射（可逆性）の保証**: `transform` 関数および関連する復号処理は、如何なるひらがな・カタカナ・特殊文字の組み合わせに対しても完全に元に戻る（全単射）ように実装し、テストでこれを厳密に証明すること。
- **波状変換の整合性**: 位置依存シフトにおける `position_counter` は、母音グループに属する文字が処理された場合のみインクリメントし、特殊文字（透過文字）ではインクリメントしないこと。これにより、暗号化と復号化でカウンターの同期が崩れることを防ぐ。

## 3. テスト規約
- テストは標準の `unittest` を使用し、`python -m unittest discover` で実行可能な構成にすること。
- 全単射性をテストするために、ランダムな文字生成によるラウンドトリップテストを最低1000回以上実行するテストケースを含めること。
